# Telegram Simulators

Проект для создания небольших текстовых игр-симуляторов в Telegram.

Каждая игра живёт в собственной папке и запускается независимо. Общий принцип: Telegram — интерфейс, игровая логика — отдельный слой.

## Игры

- [`career_simulator/`](career_simulator/) — **Карьерист**, симулятор офисной карьеры.

## Базовый стек

- Python 3.12+
- aiogram 3.x
- SQLite3
- python-dotenv
- logging

Для небольших автономных игр используется стандартный `sqlite3`: это проще и прозрачнее. SQLAlchemy 2.x и Alembic подключаются только когда модель данных действительно перерастает простой SQLite-слой или появляется общая инфраструктура между играми.

Docker — по мере необходимости для деплоя.

## Общие принципы

- не делать простые кликеры;
- строить интерес на решениях, последствиях, экономике и развитии;
- отделять Telegram-хендлеры от игрового движка;
- не добавлять инфраструктуру «на будущее», пока она не нужна;
- фиксировать в документации только важные правила и связи.
