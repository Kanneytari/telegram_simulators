# Telegram Simulators

Проект для создания небольших текстовых игр-симуляторов в Telegram.

## Цель проекта

Создание серии игр с общим техническим фундаментом. Основной интерес игр строится не на простом кликанье, а на развитии персонажа, экономике, выборе стратегии и последствиях решений.

## Технологический стек

- Python 3.12+
- aiogram 3.x
- SQLite3
- SQLAlchemy 2.x
- python-dotenv
- Docker (перспективно)

## Архитектурный принцип

Telegram является интерфейсом. Игровая логика должна быть отделена от Telegram-слоя и находиться в собственном игровом движке.

## Структура проекта

```
bot/        - Telegram интерфейс
game/       - игровые механики
database/   - работа с данными
docs/       - документация
```
