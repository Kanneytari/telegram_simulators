# NIGHTSHIFT

NIGHTSHIFT — асинхронный экономический симулятор для Telegram. Игрок управляет магазином: закупает товар, распределяет его через команду, настраивает витрину, следит за продажами, выплатами, риском и диспутами. Физические способы незаконной логистики и сокрытия не моделируются.

## Стек

- Python 3.12+
- aiogram 3.30
- SQLite3
- python-dotenv
- pytest 8

## Запуск

```bash
cd shadow_market_simulator
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Укажи `BOT_TOKEN` в `.env`, затем:

```bash
python -m app.main
```

Повторный запуск с той же БД безопасен: `Database.init()` создаёт отсутствующие таблицы, индексы и триггеры через `IF NOT EXISTS`. Это не система миграций — несовместимые изменения схемы автоматически не преобразуются.

## Конфигурация

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `BOT_TOKEN` | Telegram Bot API token | обязательно |
| `ADMIN_IDS` | Telegram ID администраторов через запятую | пусто |
| `DB_PATH` | путь к SQLite-файлу | `shadow_market.sqlite3` |
| `SIMULATION_INTERVAL_SECONDS` | период фонового цикла | `30`, минимум `10` |
| `SIMULATION_SPEED` | параметр конструктора симуляции | `1.0` |

Фактическая скорость игровых таймеров NIGHTSHIFT хранится для каждого игрока в `settings.time_multiplier` и управляется административной командой `/speed`. `SIMULATION_SPEED` в текущем финальном runtime не является основным регулятором скорости игры.

## Основной игровой цикл

```text
Товар → покупка → Склад → Складмен → Закладчик
→ фасовки → Витрина → продажи → оценки / диспуты
→ деньги и аналитика → новые решения
```

Главное меню содержит пять рабочих разделов:

- `📨 Входящие` — события и диспуты;
- `📦 Товар` — рынок предложений и переход на склад;
- `🏷 Витрина` — цены, остатки и глобальный микс фасовок;
- `👥 Команда` — сотрудники, найм, оплата и развитие закладчиков;
- `📊 Аналитика` — обзор, товары и деньги за 7/30 дней.

Подробная модель игры: `docs/GAMEPLAY.md`.

## Тестирование

Из папки `shadow_market_simulator`:

```bash
python -m pytest -q
```

CI также запускает `compileall`, ruff-проверку ошибок импортов/имён, smoke-тест свежей БД и проверку на возвращение удалённых NIGHTSHIFT-контрактов.
