# Профиль сотрудника и продуктивность

## Стартовая команда

Новая игра не создаёт опубликованные розничные позиции автоматически.

Стартовые партии остаются у оптового сотрудника. Игрок самостоятельно выбирает розничного сотрудника и объём передачи. Поэтому розничный сотрудник не получает непокрытый депозитом риск без решения игрока.

Стартовый оптовый сотрудник имеет депозит, покрывающий стартовый оптовый остаток.

## Статус сотрудника

Статус отвечает только на вопрос «чем сотрудник занят сейчас».

Возможные состояния:

- получает партию;
- готовит передачу;
- готовит позиции;
- ожидает товар;
- временная пауза;
- готовится уйти;
- свободен;
- для свободного оптовика дополнительно показывается объём, готовый к распределению.

Наличие опубликованного товара само по себе больше не делает статус сотрудника «на витрине».

В профиле активная задача дополнительно показывает товар, количество и ETA в игровых и реальных единицах времени.

## Товар в профиле

Для розничного сотрудника по каждому товару отдельно показываются:

- объём, который ещё ожидается;
- объём на руках в стадии подготовки;
- текущий опубликованный объём;
- количество живых позиций на витрине.

Для оптового сотрудника показываются:

- объём в процессе получения;
- объём, готовый к распределению;
- объём в активной передаче рознице.

Денежная ответственность и непокрытая депозитом часть отображаются отдельным блоком.

## История публикаций

`publication_events` сохраняет каждое завершённое размещение розничного сотрудника:

- `employee_id`;
- `product_id`;
- `allocation_id`;
- число единиц;
- число созданных позиций;
- игровой час события;
- реальный timestamp.

Текущие остатки `retail_positions` нельзя использовать как историческую метрику публикаций, потому что продажи уменьшают `position_count`.

## Игровые часы

`game_clock` хранит накопленное игровое время конкретного прохождения. Оно увеличивается при обычном ходе симуляции и при `/tick`; изменение `/speed` меняет скорость будущего течения времени, но не стирает уже накопленное игровое время.

## Продуктивность

Для розничного сотрудника профиль показывает:

- среднее число опубликованных позиций за игровые сутки;
- число опубликованных позиций за последние 24 игровых часа;
- изменение относительно предыдущих 24 игровых часов.

Сравнение появляется после накопления достаточной истории. Метрика зависит от фактически порученных объёмов, фасовочного микса и скорости выполнения задач, поэтому её следует интерпретировать вместе с загрузкой сотрудника.
