# Wasteland Settlement Strategy — draft

Черновой vertical slice текстовой стратегии в сеттинге `wasteland_rpg` («Контур»).

Здесь игрок уже не один ходок. Он руководит **Приютом-7**: распределяет жителей, отправляет группы в пустошь, переживает потери, накапливает ресурсы и вкладывает их в развитие поселения.

## Зачем этот прототип

У `simulation_engine` пока сформирована архитектура, но ещё нет готового runtime-пакета. Поэтому этот проект одновременно решает две задачи:

1. проверяет, интереснее ли сеттинг «Контура» как стратегия про поселение;
2. служит вторым независимым сценарием для проверки будущего `simulation_engine`.

`app/prototype_runtime.py` — **не новый общий движок**. Это маленькая временная исполняемая прослойка, повторяющая ключевую форму будущего API: `Action -> handler -> events/timers -> atomic commit`, idempotency, deterministic clock и seeded random. Когда `simulation_engine` станет исполняемым пакетом, этот файл должен исчезнуть, а scenario logic — переехать на реальный Engine практически без изменения предметных правил.

## Основной игровой цикл

```text
проверить состояние поселения
        ↓
распределить свободных жителей
        ↓
вылазка / стройка / обучение
        ↓
часть действий завершается позже
        ↓
добыча, ранения, XP, новые уровни
        ↓
улучшения поселения
        ↓
открытие более опасных секторов
        ↓
новые решения и более дорогие риски
```

Главная идея для Telegram: игроку почти всегда есть что сделать сейчас, но самые важные процессы имеют время завершения. Поэтому возвращение в игру связано не с искусственной «энергией», а с естественными результатами ранее принятых решений.

## Что уже есть в draft

- Приют-7 как управляемое поселение;
- 6 жителей с характеристиками `Сила / Ловкость / Восприятие / Интеллект`;
- здоровье, усталость, XP, уровни и очки развития жителей;
- 3 знакомых сектора: Ржавый пояс -> Промзона-12 -> Чёрный контур;
- освоение сектора 0-100 и последовательное открытие следующего;
- отряды из 1-3 жителей;
- расходы припасов на вылазку;
- асинхронное завершение вылазок через persistent-like timers;
- deterministic random для воспроизводимых результатов;
- добыча, шанс провала и ранений;
- постройки с ценой и временем улучшения;
- Водосборник, Теплица, Медпункт, Тренировочный двор и Наблюдательная вышка;
- суточное потребление еды и воды;
- пассивное производство еды/воды;
- лечение и восстановление усталости;
- обучение характеристик за очки, получаемые при повышении уровня;
- event log;
- idempotency на уровне действий;
- тесты ключевых сценариев.

## Что специально НЕ добавлено

Пока нет Telegram UI, SQLite, рейдов на поселение, торговли между городами, отношений между жителями, фракций, крафта, экипировки отрядов и сюжетных событий. Всё это имеет смысл обсуждать только после проверки базового цикла.

## Запуск demo

```bash
cd wasteland_settlement_strategy
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m app.demo
```

Demo использует `ManualClock`, поэтому ожидание можно мгновенно проматывать.

## Тесты

```bash
python3 -m pytest -q
```
