# UX-гайд Карьериста v0.4

## Цель

Интерфейс должен ощущаться как компактная мобильная игра внутри Telegram: экран быстро считывается целиком, важные параметры не сливаются, а управление всегда доступно рядом с полем ввода.

## Навигация

Все управление осуществляется через постоянную клавиатуру Telegram (`ReplyKeyboardMarkup`). Inline-кнопки под сообщениями в игровом интерфейсе не используются.

Клавиатура меняется по контексту: главный экран, проект, карьерная возможность, входящие, вложения и админские инструменты.

## Главный принцип мобильной верстки

Сообщения не должны быть растянуты по вертикали без необходимости.

- одна пустая строка только между смысловыми блоками;
- очевидные показатели сокращаются до эмодзи + числа;
- текстовая подпись сохраняется только там, где без неё число неоднозначно;
- подробности механики выносятся в отдельный экран;
- на главном экране прогресс проекта показывается процентом рядом с заголовком, без прогресс-бара;
- деньги визуально отделяются пустой строкой от карьерных характеристик.

## Визуальные маркеры

Эмодзи работают как навигационные якоря, а не как украшение каждого параметра.

Пример главного экрана:

```text
🏢 КАРЬЕРИСТ
Стажёр · день 3
━━━━━━━━━━━━
📌 ПРОЕКТ · 61%
Собрать отчёт до созвона
⏳ завтра · риск: средний

🗓 СЕГОДНЯ
⚡ 3/5 · 🎯 2/2 · ✉️ 4
🟢 Стресс: 27/100

КАРЬЕРА
Навык 9 · Репутация 7
Заметность 3 · Связи 2

💰 6 340 ₽ · Ревью через 2 дн.
```

В блоке `Сегодня` подписи `Действия`, `Возможности`, `Входящие` не нужны: значения читаются через устойчивые маркеры `⚡`, `🎯`, `✉️`.

Для стресса подпись и значение сохраняются, потому что цветовой маркер сам по себе недостаточно точен.

В блоке `Карьера` характеристики выводятся текстом без отдельных эмодзи: это компактнее и лучше читается как единый набор показателей.

## Постоянное главное меню

```text
📊 Статус        📌 Проект
🎯 Возможности   ✉️ Входящие
📈 Карьера       🧰 Ещё
```

У администратора дополнительно появляется `🧪 Админ`.

## Контекстные маркеры

- `🎯` - выбрать карьерную возможность;
- `🎲` - принять решение внутри возможности;
- `✉️` - ответить на входящее;
- `💳` - купить вложение.

## Проект

Отдельный экран проекта может быть подробнее главного и показывает прогресс, дедлайн, качество, риск, награду и три рабочие тактики. Если ключевых действий нет, тактики исчезают с клавиатуры.

## Карьерные возможности

На экране решения показываются действие, шанс успеха, характеристика, эффект успеха и риск провала. Игрок должен понимать компромисс до нажатия кнопки.

## Входящие

Входящие идут последовательно. После решения автоматически показывается следующее непрочитанное сообщение. Текст ситуации должен помещаться в несколько коротких строк.

## Результаты действий

Результат предыдущего действия показывается отдельным `blockquote` перед актуальным экраном:

```text
▸ Что произошло и почему это важно.
```

## Ошибки

Ошибка объясняет причину и следующий возможный шаг. Не использовать технические термины реализации.

## Тон

Коротко, предметно, немного сатиры. Один термин для одной сущности. Сначала факт, затем последствие.

## Критерий качества

На телефоне пользователь должен за 3-5 секунд понять, где находится, что сейчас важно и какие действия ему доступны, по возможности не прокручивая само игровое сообщение.
