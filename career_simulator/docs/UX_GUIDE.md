# UX-гайд Карьериста v0.3

## Цель

Интерфейс должен ощущаться как аккуратная мобильная игра внутри Telegram: пользователь быстро считывает экран, понимает текущую проблему и выбирает действие без поиска нужной кнопки под старым сообщением.

## Главное правило навигации

Все управление осуществляется через постоянную клавиатуру Telegram (`ReplyKeyboardMarkup`) рядом с полем ввода.

Inline-кнопки под сообщениями в игровом интерфейсе не используются.

Клавиатура меняется в зависимости от контекста:

- главный экран - основные разделы;
- проект - три тактики работы;
- карьерная возможность - варианты текущего решения;
- входящие - ответы на текущую ситуацию;
- вложения - список покупок;
- админский экран - тестовые инструменты.

Пользователь не должен прокручивать историю чата, чтобы найти рабочую кнопку.

## Визуальная система

Сообщения должны иметь одинаковый ритм:

1. один визуальный маркер раздела;
2. короткий заголовок капсом;
3. тонкий разделитель `━━━━━━━━━━━━`;
4. 2-4 логических блока;
5. пустая строка между блоками;
6. важные числа выделяются жирным только там, где это помогает принять решение.

Пример:

```text
📌 ПРОЕКТ
━━━━━━━━━━━━
Название проекта
▓▓▓▓▓░░░░░ 52%

⏳ Дедлайн: завтра
◆ Качество: рабочее
▲ Риск: высокий

ТАКТИКА
⚡ Быстро - ...
🧠 Надёжно - ...
🤝 С коллегами - ...
```

Эмодзи используются как визуальные маркеры сущностей и кнопок, а не как украшение каждого предложения.

## Главный экран

Главный экран отвечает на пять вопросов:

- кто я и какой сейчас игровой день;
- что происходит с текущим проектом;
- сколько ключевых действий осталось;
- есть ли сегодня неразыгранные возможности и входящие;
- насколько я готов к следующему карьерному ревью.

Детали механик открываются в отдельных разделах.

## Постоянное главное меню

Базовая клавиатура:

```text
📊 Статус        📌 Проект
🎯 Возможности   ✉️ Входящие
📈 Карьера       🧰 Ещё
```

У администратора дополнительно появляется `🧪 Админ`.

Кнопки главного меню не меняют названия без необходимости. Мышечная память важнее попытки каждый раз показать состояние прямо в подписи кнопки.

## Контекстные маркеры

Для динамических решений используются разные префиксы:

- `🎯` - выбрать карьерную возможность;
- `🎲` - принять решение внутри возможности;
- `✉️` - ответить на входящее;
- `💳` - купить вложение.

Это позволяет мгновенно отличать тип действия даже при похожих формулировках.

## Проект

Экран проекта всегда показывает:

- прогресс;
- дедлайн;
- качество;
- риск;
- базовую награду;
- объяснение трёх тактик.

Игрок должен понимать не только `что нажать`, но и `зачем`.

Если ключевых действий нет, рабочие тактики исчезают с клавиатуры.

## Карьерные возможности

Экран списка показывает 3 ситуации и их базовую ценность.

После выбора возможности клавиатура заменяется вариантами текущего этапа.

Каждый вариант прямо на экране содержит:

- действие;
- шанс успеха;
- характеристику, от которой он зависит.

После выбора сначала показывается короткий результат, затем следующий этап.

Игроку не нужно возвращаться в список между тремя этапами.

## Входящие

Входящие идут последовательно. После решения автоматически отображается следующее непрочитанное сообщение.

Это быстрый поток, поэтому текст каждой ситуации должен помещаться в 2-3 коротких предложения.

## Результаты действий

Результат предыдущего действия отображается отдельным `blockquote` перед актуальным экраном.

Формат:

```text
▸ Что произошло и почему это важно.
```

Не перечислять все технические изменения базы данных. Игроку важны понятные последствия.

## Ошибки

Ошибка должна отвечать на два вопроса:

- почему действие невозможно;
- что пользователь может сделать вместо этого.

Плохой вариант:

`Недоступно.`

Хороший вариант:

`Ключевые действия на сегодня закончились. Разбери входящие или дождись следующего активного дня.`

## Тон

- коротко;
- немного сатиры, но без стендапа в каждом сообщении;
- один термин для одной сущности;
- без технических слов вроде `callback`, `row`, `state`;
- сначала факт, потом последствие.

## Критерий качества

Игрок, который открыл любой экран после паузы в несколько часов, за 3-5 секунд должен понять:

1. где он находится;
2. что сейчас важно;
3. какие действия ему доступны;
4. чем эти действия отличаются друг от друга.
