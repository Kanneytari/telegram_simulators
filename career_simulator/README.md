# Карьерист

Telegram-симулятор офисной карьеры на Python, aiogram 3 и SQLite.

Игрок начинает стажёром и растёт через навык, репутацию, заметность и связи, одновременно управляя стрессом и дедлайнами.

## Игровая сессия

Один активный день содержит 5 ключевых действий, 6 входящих рабочих ситуаций и до 2 фокус-сессий по проекту. Поэтому игру можно открыть на пару минут или разыграть полноценную сессию примерно на 15-20 минут без бесконечного фарма.

## Стек

- Python 3.12+
- aiogram 3
- SQLite (`sqlite3`, без ORM)
- python-dotenv

LLM в базовую версию не встроена: основной игровой цикл должен быть дешёвым, детерминированным и тестируемым.

## Запуск

```bash
cd career_simulator
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env`:

```text
BOT_TOKEN=123456:your_bot_token
ADMIN_IDS=123456789,987654321
DB_PATH=career_simulator.sqlite3
```

`ADMIN_IDS` - список числовых Telegram ID через запятую. Сам `.env` находится в `.gitignore`.

Запуск:

```bash
python3 -m app.main
```

## Админские функции

- `/reset` - сбросить прогресс своего персонажа с подтверждением;
- `/fast` - переключить быстрый режим;
- `/fast on` и `/fast off` - явно включить или выключить его;
- после расходования 5 действий в быстром режиме появляется `Следующий день`.

Быстрый режим запускает штатный переход дня: зарплату, восстановление стресса, дедлайны, карьерные ревью и новые проекты. Дневные записи предыдущего тестового дня архивируются.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Структура

```text
app/
  admin.py            # тестовые функции администраторов
  config.py           # конфигурация
  content.py          # базовый игровой контент
  db.py               # основная схема SQLite
  game.py             # базовый карьерный цикл
  session.py          # входящие и фокус-сессии
  session_content.py  # контент длинной сессии
  ui.py               # единое форматирование экранов
  handlers.py         # Telegram-хендлеры
  keyboards.py        # inline-кнопки
  main.py             # точка входа

docs/
  GAME_DESIGN.md
  DATA_MODEL.md
  UX_GUIDE.md
```

Telegram-слой не содержит игровой баланс. Правила находятся в сервисах, а оформление экранов централизовано в `ui.py`.
