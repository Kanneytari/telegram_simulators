# Карьерист

Telegram-симулятор офисной карьеры на Python, aiogram 3 и SQLite.

Игрок начинает стажёром и растёт через навык, репутацию, заметность и связи, одновременно управляя стрессом, дедлайнами, качеством проектов и карьерными рисками.

## Игровая сессия

Один активный день содержит:

- 5 ключевых действий;
- тактическую работу над проектом через скорость / качество / риск;
- 3 случайные карьерные возможности, из которых можно разыграть до 2;
- по 3 решения внутри каждой выбранной возможности;
- 4 коротких входящих ситуации;
- карьерное вложение, портфолио и подготовку к ревью.

Цель дизайна - поддерживать и быстрый заход на 1-2 минуты, и полноценную сессию до 15-20 минут без бесконечного фарма.

## Управление

Игровое управление находится в постоянной клавиатуре Telegram рядом с полем ввода (`ReplyKeyboardMarkup`).

Inline-кнопки под сообщениями не используются.

Главное меню:

```text
📊 Статус        📌 Проект
🎯 Возможности   ✉️ Входящие
📈 Карьера       🧰 Ещё
```

Контекстные экраны временно заменяют клавиатуру своими действиями, например тактиками проекта или вариантами решения карьерной ситуации.

## Стек

- Python 3.12+
- aiogram 3
- SQLite (`sqlite3`, без ORM)
- python-dotenv

LLM в базовую версию не встроена: основной игровой цикл должен быть дешёвым, управляемым и тестируемым.

## Запуск

```bash
cd career_simulator
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env`:

```text
BOT_TOKEN=123456:your_bot_token
ADMIN_IDS=123456789,987654321
DB_PATH=career_simulator.sqlite3
```

`ADMIN_IDS` - список числовых Telegram ID через запятую. Сам `.env` находится в `.gitignore`.

Запуск:

```bash
python3 -m app.main
```

## Админские функции

Основное управление находится в кнопке `🧪 Админ` внутри бота:

- включение/выключение быстрого режима;
- `Следующий день` после расходования 5 действий;
- полный reset персонажа с подтверждением.

Команды `/fast` и `/reset` сохранены как резервный способ управления.

Быстрый режим запускает штатный переход дня: зарплату, восстановление стресса, дедлайны, карьерные ревью и новые проекты. Дневные записи предыдущего тестового дня архивируются.

## Структура

```text
app/
  admin.py                # тестовые функции администраторов
  config.py               # конфигурация
  content.py              # базовый игровой контент
  db.py                   # основная схема SQLite
  game.py                 # базовый карьерный цикл
  project_play.py         # прогресс, качество и риск проектов
  opportunities.py        # карьерные возможности и портфолио
  opportunity_content.py  # сценарии многошаговых возможностей
  session.py              # короткие входящие ситуации
  session_content.py      # контент входящих
  ui.py                   # единое форматирование экранов
  handlers.py             # Telegram-хендлеры
  keyboards.py            # постоянные и контекстные reply-клавиатуры
  main.py                 # точка входа

docs/
  GAME_DESIGN.md
  DATA_MODEL.md
  UX_GUIDE.md
```

Telegram-слой не содержит игровой баланс. Правила находятся в сервисах, а оформление экранов централизовано в `ui.py`.
