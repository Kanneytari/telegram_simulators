# Контур

Текстовая single-player RPG для Telegram о рискованных вылазках в постапокалиптические промзоны.

Главный цикл: **выбрать сектор → искать добычу → пережить события/бой → решить, идти глубже или возвращаться → закрепить добычу → продать и усилить персонажа**.

## Что уже работает

- управление только через inline-кнопки;
- 3 сектора с разными требованиями, добычей и опасностью;
- растущая угроза во время вылазки;
- незакреплённая добыча, которая теряется при смерти;
- пошаговые бои: выстрел, прицеливание, ближний бой, аптечка, отступление;
- опасные находки с явным шансом успеха;
- уровни и 4 характеристики: Сила, Ловкость, Восприятие, Интеллект;
- 1 очко характеристики за каждый новый уровень;
- здоровье по формуле `20 + уровень × 20`;
- Ловкость снижает входящий урон;
- требования предметов к характеристикам;
- оружие, броня, патроны, аптечки;
- торговец и продажа ресурсов;
- SQLite-сохранения.

## Запуск

```bash
cd wasteland_rpg
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
cp .env.example .env
# впиши BOT_TOKEN в .env
python3 -m app.main
```

## Тесты

```bash
cd wasteland_rpg
python3 -m pytest -q
```

## Архитектура

- `app/content.py` — игровой контент, характеристики, требования предметов и баланс;
- `app/db.py` — простая SQLite-схема;
- `app/game.py` — вся игровая логика без Telegram;
- `app/ui.py` — текст экранов;
- `app/keyboards.py` — inline-кнопки;
- `app/handlers.py` — маршрутизация Telegram callback'ов;
- `docs/GAME_DESIGN.md` — принципы дизайна и границы MVP.

Код намеренно остаётся компактным: пока игра небольшая, важнее держать полный игровой цикл читаемым и тестируемым.
