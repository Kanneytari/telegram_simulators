# Контур

Текстовая single-player RPG для Telegram про вылазки, дороги между поселениями, торговлю и развитие персонажа.

Главный цикл: **вылазка → риск и решения → добыча → безопасное поселение → торговля/экипировка → дорога в новый узел мира**.

## Что уже работает

- управление через inline-кнопки;
- 4 безопасных поселения и 3 последовательных маршрута по 10 участков;
- 10 вылазочных локаций: 3 исходные в Приюте-7 и дополнительные уникальные сектора в новых поселениях;
- более опасные сектора открываются после достижения угрозы 100/100 в предыдущем секторе;
- максимальная достигнутая угроза по сектору сохраняется между вылазками;
- закрытые местные сектора остаются видимыми в интерфейсе с 🔒 и понятным условием открытия;
- дорожные события, бои и риск потерять торговый груз;
- локальные рынки с разными ценами покупки и продажи ресурсов;
- отдельный торговый груз и безопасный склад;
- случайные события с восстанавливающимися весами: одно событие не повторяется два шага подряд, частые и редкие события восстанавливаются с разной скоростью;
- сценарные развилки с несколькими решениями;
- характеристики могут открывать дополнительную информацию в событиях;
- уровни и 4 характеристики: 💪 Сила, 🏃 Ловкость, 👁 Восприятие, 🧠 Интеллект;
- стоимость следующего уровня всегда считается по формуле `40 × 1.35^(уровень−1)` с округлением до 5 XP;
- верхнего ограничения характеристик нет;
- 1 очко характеристики за каждый новый уровень;
- здоровье по формуле `20 + уровень × 20`;
- 5 слотов экипировки: оружие, броня, рюкзак, головной убор, устройство;
- упрощённый бой: стрельба, очереди, укрытие, аптечка, отход и ближний бой только после автоматического сближения противника;
- торговец с категориями Оружие / Экипировка / Медицина;
- команда `/reset` с подтверждением для полного сброса прогресса;
- SQLite-сохранения.

## Запуск

```bash
cd wasteland_rpg
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
cp .env.example .env
# впиши BOT_TOKEN в .env
python3 -m app.main
```

## Тесты

```bash
python3 -m pytest -q
```

## Архитектура

- `app/content.py` — контент мира, рынки, предметы, враги и баланс;
- `app/event_pools.py` — базовые веса и скорость восстановления случайных событий;
- `app/sector_progression.py` — последовательность освоения вылазочных секторов;
- `app/progression.py` — формула опыта и расчёт уровней;
- `app/db.py` — SQLite-схема;
- `app/game.py` — базовая игровая логика без Telegram;
- `app/gameplay.py` — текущие правила боя и ротации событий;
- `app/service.py` — runtime-правила прогрессии и освоения секторов;
- `app/ui.py` — основные тексты экранов;
- `app/combat_view.py` — компактный боевой экран и боевые кнопки;
- `app/progression_view.py` — экран прогрессии персонажа;
- `app/sector_view.py` — экран локальных секторов и условий открытия;
- `app/keyboards.py` — остальные inline-кнопки;
- `app/handlers.py` — маршрутизация Telegram callback'ов;
- `docs/GAME_DESIGN.md` — актуальная модель игровых систем.
