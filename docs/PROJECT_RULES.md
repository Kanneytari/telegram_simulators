# Базовые принципы проекта Telegram Text Games

## Назначение проекта

Создание небольших текстовых игр в Telegram в жанре симуляторов.

Главная цель - создавать игры с простым входом, но глубокой системой развития. Интерес должен строиться на выборе решений, управлении ресурсами, риске, последствиях и развитии игровых систем.

## Стек

- Python 3.12+
- aiogram 3.x
- SQLite3
- SQLAlchemy 2.x
- python-dotenv
- logging
- Docker (перспективно)
- Alembic (при усложнении БД)

## Архитектурные принципы

- Telegram используется только как интерфейс.
- Игровая логика не должна зависеть от Telegram API.
- Код должен быть разделен на слои: интерфейс, игровая логика, база данных.
- Компоненты игры должны быть переиспользуемыми.

## Основные игровые принципы

- Не делать простые кликеры.
- Основной интерес: решения, экономика, риск, развитие и исследование.
- Каждое действие игрока должно иметь последствия.
- Ресурсы и деньги должны иметь применение.

## Разработка новых игр

Каждая игра собирается из модулей:

- игровой цикл;
- экономика;
- прогрессия;
- события;
- предметы;
- задания;
- риск и награда.

## Правила кода

- Использовать type hints.
- Разделять ответственность модулей.
- Не хранить секреты в коде.
- Избегать больших монолитных файлов.
- Писать код с расчетом на расширение.

## MVP подход

На старте:

- одна игра;
- один Telegram-бот;
- SQLite;
- минимальный набор механик.

Сначала проверяется игровая механика, затем добавляется инфраструктура.
