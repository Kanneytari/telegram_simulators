# Базовые принципы проекта Telegram Text Games

## Назначение проекта

Создание небольших текстовых игр в Telegram в жанре симуляторов.

Главная цель - создавать игры с простым входом, но глубокой системой развития. Интерес должен строиться на выборе решений, управлении ресурсами, риске, последствиях и развитии игровых систем.

## Стек

- Python 3.12+
- aiogram 3.x
- SQLite3
- `sqlite3` для небольших автономных MVP
- python-dotenv
- logging
- Docker - при необходимости деплоя
- SQLAlchemy 2.x + Alembic - только при реальном усложнении модели данных или общей инфраструктуры

## Архитектурные принципы

- Telegram используется только как интерфейс.
- Игровая логика не должна зависеть от Telegram API.
- Код разделяется на интерфейс, игровую логику и работу с данными.
- Переиспользование не должно создавать абстракции раньше времени.
- Новая инфраструктура добавляется только под существующую задачу.

## Основные игровые принципы

- Не делать простые кликеры.
- Основной интерес: решения, экономика, риск, развитие и исследование.
- Каждое действие игрока должно иметь последствия.
- Ресурсы и деньги должны иметь применение.
- Регулярное возвращение должно давать новую игровую ситуацию, а не только награду за вход.

## Разработка новых игр

Каждая игра получает собственную папку и независимую точку запуска. Внутри неё проектируются только реально нужные модули: игровой цикл, экономика, прогрессия, события, задания, риск и награда.

## Правила кода

- Использовать type hints.
- Разделять ответственность модулей.
- Не хранить секреты в коде.
- Избегать больших монолитных файлов.
- Предпочитать простое решение расширяемому «на всякий случай».
- Игровую логику тестировать отдельно от Telegram API.

## MVP подход

На старте:

- одна игра;
- один Telegram-бот;
- SQLite;
- минимальный набор механик.

Сначала проверяется, интересно ли играть. Только затем добавляются новые механики и инфраструктура.
